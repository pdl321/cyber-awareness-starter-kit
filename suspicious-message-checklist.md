**Suspicious Message Checklist**
Use this checklist when an unexpected text, email, QR code, or login request appears.

**Stop**

•	Do not select the link.

•	Do not scan the QR code.

•	Do not reply to the sender.

•	Do not provide a password or personal information.

**Check**

•	Ask whether the message was expected.

•	Check the sender’s address or phone number.

•	Look for urgency, threats, or unusual payment requests.

•	Verify the request using a trusted phone number or website.

**Report**

•	Take a screenshot if workplace policy allows it.

•	Report the message to a supervisor or designated security contact.

•	Include when the message arrived and how it was received.

•	Delete the message only after receiving instructions.

**For Managers**

Record the report, notify the appropriate security contact, and tell the employee what to do next. Do not blame an employee for reporting a suspicious message.

**Measuring Effectiveness**

The organization can review:

•	The number of suspicious messages reported

•	The time between receiving and reporting a message

•	Common questions employees ask

•	Whether employees know where to report a concern

Review the results monthly and update the checklist when employees need clearer instructions.
