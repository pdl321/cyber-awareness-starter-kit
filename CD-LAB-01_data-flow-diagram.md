Here is a simple table and diagram with all seven parts. TB1–TB3 mark trust boundaries.

| Boundary | Why it matters |
| --- | --- |
| **TB1 — Web client ↔ API** | Learner-controlled input enters academy systems. Validate requests, Sanitize input and check access. |
| **TB2 — API ↔ AI provider** | Data leaves academy control. Minimise what is sent and check returned drafts. |
| **TB3 — API ↔ Staff console** | Staff have privileged access. Require strong authentication and limit permissions. |
